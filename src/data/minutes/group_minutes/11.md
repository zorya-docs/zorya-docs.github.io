### 1. **Message to Professors**
- **Summary of progress:**
  - **Dicoogle Plugin & Queue**:  
    The Dicoogle plugin is working correctly. We now have a Redis instance, where the path of each indexed image is sent. In a separate container, a Python script consumes the queue and runs the model.  
    Current issue: Conversion of DCM to TIFF still not fixed.
  
  - **Database (MongoDB)**:  
    Models for all entities are complete. The latest change was a restructure of the algorithm model to include more information (e.g., dependencies, inference entrypoint, labels_output, etc.). Endpoints for studies are developed but still need to be tested with real data.

  - **Viewer**:  
    The JAR file has been placed in the plugins folder, but running `docker-compose up` causes a Dicoogle error related to Lucene (`java.lang.ClassNotFoundException: org.apache.lucene.queryparser.classic.ParseException`). Further debugging is needed, but if the professor knows the cause of the error, it would save time so we can focus on more important issues.

  - **AI Models**:  
    Currently testing the **BiomedParse model** from HuggingFace. This model analyzes images and detects specific cell types (e.g., neoplastic and inflammatory cells). The input is a DICOM/PNG/JPG image, and the output is a PNG image with markers showing detected cells, along with text explaining the area, perimeter, and circularity of each cell. This is still not working within the project; only local testing has been done.

  - **Frontend**:  
    The **Assigned Work** and **Actions** pages have been updated according to the professors' feedback. We are now trying to integrate the models into the project so that they can be used on images within the platform, especially on the **Actions** page.
